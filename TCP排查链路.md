## 抓包

先确认系统：
```bash

cat /etc/os-release
```

Ubuntu / Debian
```bash
apt update
apt install -y tcpdump
```

CentOS / RHEL
```bash
yum install -y tcpdump
```

验证
```bash
tcpdump --version
```


抓包
```bash
tcpdump -i any port 62201 -nn -A | grep heartbeat
```

抓包存文件
```bash
tcpdump -i any "tcp port 61002 or tcp port 61100" -w capture.pcap
```

这段数据是一个典型的 **ASCII 文本协议**，每个十六进制数对应一个字符。

### 报文内容详细拆解表

| ****字节偏移 (Hex)** | **十六进制 (Hex)**    | **对应字符 (ASCII)**   | **字段定义**       | **备注**            |
| ---------------- | ----------------- | ------------------ | -------------- | ----------------- |
| `00`             | `24`              | `$`                | **Prefix**     | 报文起始引导符           |
| `01-09`          | `68 65 61 ... 74` | `heartbeat`        | **MsgType**    | 消息类型：心跳/定位上报      |
| `0a`             | `2c`              | `,`                | **Splitter**   | 字段分隔符             |
| `0b-11`          | `73 65 ... 3a`    | `serial:`          | **Key**        | 序列号标签             |
| `12-1d`          | `44 30 ... 34`    | **`D0CF13E03FF4`** | **Value**      | **设备唯一 SN 编号**    |
| `1e`             | `2c`              | `,`                | **Splitter**   | 字段分隔符             |
| `1f-22`          | `6c 61 74 3a`     | `lat:`             | **Key**        | 纬度标签 (Latitude)   |
| `23-2d`          | `32 35 ... 36`    | **`25.71995036`**  | **Value**      | **当前纬度**          |
| `2e`             | `2c`              | `,`                | **Splitter**   | 字段分隔符             |
